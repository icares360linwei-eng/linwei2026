> **V7.0** —— 守正 · 开物 · 共生

```bash

```

## 插图：不画，是长出来的

第 015 章把「空状态与场景叙事的插画」列为待定项，并判断它应改为影像而非插画；
第 017 章注明「需你确认方向」。本站按**第三条路**实现：既不摆拍也不手绘，
让插图按规则生成 —— 这正是「开物」在视觉上的落点。

六幅扉画（`assets/js/lattice.js`）各由一个纯函数与一个确定性种子生成，
画的都是本典自己的数据：色阶、构造网格、闭环量级、令牌族规模。
没有一个位图文件；不引入任何新色相，不加渐变、发光与 3D。
若最终决定走实景影像，这一层可整体替换而不影响任何令牌与组件。

五实体点阵标记同样由规则生成：48 × 48 网格、点径六档（2.0 / 2.2 / 2.4 / 2.6 / 3.0 / 3.4）、
点数 6–8 枚。**原缺件清单上的 150 枚待画 SVG 因此全部废止。**

## 对比度门禁

`build/audit.mjs` 在真实浏览器里实测 **2 种明暗 × 5 个实体 × 22 组前景/背景 = 220 项**，
任一项不达标即退出码 1。

```bash
npm i -D playwright        # 仅门禁需要，站点本身零依赖
node build/audit.mjs
```

当前结果：**220 项全部达标**，正文对比度 9.75 – 15.51 : 1。

## 本站对令牌层做的三处修正

实测门禁跑出三处原值不达 WCAG AA，已在 `assets/css/tokens.css` 就地修正并注明原因：

| 令牌 | 原值 | 实测 | 现值 |
|---|---|---|---|
| `--text-subtle`（浅色） | `ink-500` | 3.83 : 1 | `ink-600` |
| `--field-placeholder` | `ink-500` | 3.99 : 1（浅）/ 4.44 : 1（暗） | `ink-600` / `ink-400` |
| `--brand-600`（暗色） | `mix(brand-400 82%, ink-50)` | STG 4.18 / STI 4.28 : 1 | `mix(… 74%, ink-50)` |

浅色下的第三层级因此并到 `ink-600`，层级改由字号与字重承担；
暗色下 `ink-500` 达 5.6 : 1，四级仍成立。
**建议令牌方补一阶 `ink-550`（目标 4.5–5 : 1）以恢复浅色四级。**

## 站点自身遵守的十二条

本站即验收样本。逐条可指认：

01 全部颜色走令牌，无硬编码色值 · 02 间距只用 4px 步进 · 03 全墨为底，加色处均可论证
04 主操作用玄墨，实体色只作 2px 刻度，朱与金每屏各一处 · 05 状态色独立声明，涨跌颜色 + 方向图标双重编码
06 无纯黑纯白（页底 `#FBF9F5`，卡面 `#FFFEFB`） · 07 一重边界：描边与阴影不同现，面板不嵌套
08 四样动效仅用于品牌面，产品面组件只有 150ms 微交互 · 09 八状态齐备，键盘可达，焦点永远可见
10 220 项对比度实测全达标，触摸目标 ≥44px · 11 品牌标记全部由生成规则产出
12 五实体只切 `data-theme`，版式与组件零差异
