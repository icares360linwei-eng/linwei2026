Color

色彩：高阶不靠色度，靠明度落差

同一色相，oklch(0.32 0.09) 显贵，oklch(0.45 0.22) 显廉。宋瓷、明式家具、官式建筑的朱墨金用的都是掺了灰的矿物颜料；瑞士编辑设计同样是近乎单色加一个深色重点。

Themes

主题切换

data-theme="stg|ste|sti|sth|edu" 重映射 --brand-50…800 整族；data-color-scheme="dark" 以焦墨为底，主操作翻转为宣纸白。不另写一套组件。

Contrast

对比与透明度

实体色 600 档在宣纸底上均 ≥8:1，白字在其上 ≥4.5:1。深底浅色文字换 ink 色阶实色，不用 alpha 调淡。透明度只三处合法：粘性顶栏、模态遮罩、压在实景上的溯源胶囊。

为什么必须独立声明
三支状态色在源码里直接别名实体色，这正是「松烟绿同时表示 STE 与上涨」的成因。V7.0 将四支全部独立声明，取值不再随 data-theme 变动。error 与印章朱同值是有意为之 —— 错误态因此自动继承「每屏一处」的配额。
005 / 021
Module identity

模块识别：三层结构，色相只有一个

实体色压到 2px 刻度之后，一家实体内部的多个业务模块就失去了识别手段。解法不是给每个模块发一个色相 —— 那会让 STE 一家公司里出现五种颜色，直接推翻配色配额；而是让模块走同一色相的明度档。

三层结构
Layer 1色相

实体层

五实体各一色相，由 data-theme 切换。跨实体的差异只在这一层表达。

Layer 2明度 + 编号 + 点阵

模块层

同一实体色阶的四个明度档（400 / 500 / 600 / 700）+ 模块编号 M1–M5 + 点阵密度。三重编码，不新增任何色相。

Layer 3状态色族

状态层

四支独立状态色，与前两层不共用取值。因此「达标」在任何实体任何模块里都是同一个绿。

Typography

字体：三轨分工，九级字阶

字阶落差是大气的主要来源：同屏最大字与正文的比值不低于三倍，否则版面就平。四个字族按职责收成三轨 —— 展示、界面、标识 —— 各轨互不越界。

三轨分工
Track 01 · Display
守正 · 开物 · 共生

Noto Serif SC 200–300。仅 H1/H2、章节标题与哲学引文。负字距 -0.032em。引文行高 1.9–2.1。

Track 02 · Interface
今日碳配额剩余 12,800 吨

Noto Sans SC 承载中文，Space Grotesk 承载全部西文与数值。字距归零。数值统一 300 字重 + tabular-nums。

Track 03 · Identifier
STE.RC.20260904

JetBrains Mono 承载单号、批次、哈希、日志时间戳与 Token 名。不承载计量数值。

排版纪律 · 待补 · 有意替换
Discipline

排版纪律

标题一律 word-break: keep-all，否则「热电联产」会被劈成两行；大标题加 text-wrap: balance。

Pending

字体文件待补

原稿指定霞鹜文楷与思源系列但未提供文件。当前用 Noto Serif SC / Noto Sans SC 近似替代。提供授权字体文件后改为 @font-face 自托管。

Substitution

Space Grotesk 是有意替换

原稿指定 Inter。Inter 过于通用，Space Grotesk 的几何骨架更贴近 SINOTAO 字标的重几何无衬线气质，此项不回退。
