## 2. CONTENT FUNDAMENTALS · 内容与文案

**语言**：简体中文第一语言（必译），英文第二语言（品牌系统与开发者文档必译），繁体中文按需。西文只出现在眼标、数值、代码与 Token 名里。

**人称**：对用户称「你」，不称「您」（除对外正式函件与监管场景）。系统不自称「我」；只有品牌叙事段落可用「我们」。

**语调**：正式度中高、温度中、简洁度高。儒侠气质——稳重而不迂腐，精进而不冒进。不喧哗、不自炫，但精确、但温暖。

**五实体语调差异**

| 实体 | 正式度 | 温度 | 示例 |
|------|:---:|:---:|------|
| STG | 中高 | 中 | 「超过 500 万元需集团审批。」 |
| STE | 中 | 中高 | 「今日碳配额剩余 12,800 吨，建议优化 CFB 燃烧参数。」 |
| STI | 中高 | 中 | 「报关单 #STI-2026-0718 已提交，预计 2 小时内审核。」 |
| STH | 高 | 高 | 「检测报告已生成。请注意：本结果仅供专业医师参考。」 |
| EDU | 中 | 高 | 「小明同学，你的阅读能力比上月提升了 15%，继续加油！」 |

**按钮与错误文案：写动作，不写「确定」**

| 场景 | ✅ | ❌ |
|------|----|----|
| 提交表单 | 保存并提交 | 确定 |
| 删除操作 | 删除订单 #1024 | 是 |
| 必填为空 | 请输入你的手机号码 | 字段不能为空 |
| 格式错误 | 手机号应为 11 位数字 | 输入格式不正确 |
| 网络错误 | 网络连接中断，请检查网络后重试 | 错误 500 |
| 无数据 | 暂无数据。创建第一条记录，从这里开始。 | 暂无数据 |
| 无结果 | 未找到匹配结果。试试调整关键词？ | 无结果 |

**大小写与标点**：中文正文用全角标点，引号用「」；西文用半角，引号用 “”。**眼标（`.u-eyebrow`，0.18em 字距 + 全大写）只用于西文**——用在汉字上会把字拉散；中文小标签用 `.u-label`（12px、500 字重、零字距）。中文标题不加句末句号。中文与西文/数字之间留 1/4em 空隙（视觉空格）。

**术语一致性（不可替换）**：源裕兴创新未来 / 九派国有能源（「九派能源」仅内部简称，不上界面）/ 守正 · 开物 · 共生 / 金三角罗盘 / 太极流纹。

**数字格式**：金额 `¥1,234.56`；百分比 `15.7%`；日期 `2026-07-20`（ISO 8601）；时间 `14:30`（24 小时制）；大数 `1,280 万` / `12.8 亿`。所有数值走西文字族 + `tabular-nums`。

**Emoji**：不使用。界面里没有一个 emoji，状态一律由 Material Symbols 图标 + 文字 + 语义色三重表达。Unicode 符号仅限 `⌘` `⌥` 等快捷键记号与 `≥ ≤ ×` 等数学符号。

**AI 界面文案**：置信度 ≥85% 写「高度可信」且不标百分比；60–84% 写「置信度 75%，建议人工复核」；<60% 写「置信度较低（42%），仅供参考」。

## 3. VISUAL FOUNDATIONS · 视觉基础

### 色彩 · 矿物颜料逻辑

**核心判断：高阶不靠色度，靠明度落差。** 同一色相，oklch(0.32 0.09) 显贵，oklch(0.45 0.22) 显廉。宋瓷、明式家具、褪色壁画、官式建筑的朱墨金，用的都是掺了灰的矿物颜料；瑞士编辑设计同样是近乎单色加一个深色重点。两边指向同一条规律，本系统按它重建了全部色值。

**结构是「墨为主、朱为章、金为贵、实体色为身份标记」四层：**

- **墨与宣（约 80%）**：底色 `--ink-50 #FBF9F5`（宣，去掉了旧版的奶油黄），正文 `--ink-700`，标题与**主操作按钮** `--ink-900 #17140F`。墨是最贵的颜色——主按钮用墨而不用品牌色，这是本系统最重要的一条色彩决策。绝不用纯黑 `#000`；卡面用 `#FFFEFB` 而非纯白。
- **印章朱（约 5%）**：`--zhu-600 #8A3323`，取自印泥与官式朱。全站唯一的重点色，用于章节起点的一枚方块（`--seal`）、错误态、以及需要真正强调的地方。每个章节仅一枚印章。
- **古铜金（约 5%）**：`--gold-400 #B9A177`（比旧版去橙留灰，是箔金不是镀金）。品牌营销面的 CTA、奖项资质、深底眼标。每屏最多一处。
- **五实体矿物色（约 15%）**：色度统一压到 0.04–0.09、明度对齐 0.32–0.40 带。**正确用法是 2px 细线刻度 + 代号，不是 40px 填色块**——旧版把五个高色度色块并排铺开，那是色卡展示，不是品牌。实体色驱动：选中态、导航激活、链接、焦点环、图表首序列。

> **已废止**：`#851EA3` / `#196B42` / `#1E4082` / `#208F9B` / `#B81E1E`（V6.0 高色度色值）。色相关系保留，色度与明度整体重制。

- **主题切换**：`<html data-theme="stg|ste|sti|sth|edu">` 重映射 `--brand-50…800` 整族；`data-color-scheme="dark"` 以焦墨为底，主操作翻转为宣纸白。
- **可访问性**：实体色 600 档在宣纸底上对比度均 ≥8:1，白字在其上 ≥4.5:1，压深后不再需要单独的加深变体。

### 字体

| 令牌 | 字体 | 用途 |
|------|------|------|
| `--font-display` | Noto Serif SC | 中文展示与标题（200–400 字重；Display 2XL 达 112px） |
| `--font-serif` | Noto Serif SC | 引文、哲学锚点正文（1.8 行高） |
| `--font-sans` | Noto Sans SC | 界面正文与 H4–H6 |
| `--font-western` | Space Grotesk | 西文正文、全部数值、眼标 |
| `--font-wordmark` | Poppins 800 | 无 SVG 时的 SINOTAO 字标兜底 |
| `--font-mono` | JetBrains Mono | 代码与 Token |

**⚠️ 字体替代说明（需用户确认）**：原稿指定霞鹜文楷 LXGW WenKai（品牌展示）、思源宋体、思源黑体、Inter、JetBrains Mono，但**未提供任何字体文件**。当前用 Google Fonts 近似替代：霞鹜文楷 → Noto Serif SC（无楷体替代品，字形气质差异明显）；思源宋体 / 黑体 → Noto Serif SC / Noto Sans SC（同源，差异极小）；Inter → **Space Grotesk**（有意替换：Inter 过于通用，Space Grotesk 的几何骨架更贴近 SINOTAO 字标的重几何无衬线气质）。**请提供霞鹜文楷与思源系列的授权字体文件，我会换成 `@font-face` 自托管。**

**字阶落差是「大气」的主要来源**：章节标题 `clamp(34px, 4.4vw, 64px)` 配 200 字重与 -0.032em 负字距，正文 15–16px，KPI 数值 `clamp(30px, 3.1vw, 44px)` 配 300 字重。同屏最大字与正文的比值不低于 3 倍，否则版面就「平」。眼标一律 11–12px 大写西文 + 0.16–0.18em 字距；承载中文的小标签改用 `.u-label`（12px、500 字重、零字距）。

排版纪律：展示级负字距、界面级零字距；标题一律 `word-break: keep-all`（已写进 `base.css` 的 h1–h6），否则「热电联产」这类固定术语会被劈成两行；中文度量 35em；正文行高 1.6–1.75，引文 1.9–2.1；大标题加 `text-wrap: balance`。**注意**：`em` 宽度约束必须写在标题元素自身上（按它自己的字号解析），写在父容器上会按继承的正文字号解析，把大标题挤成两字一行。

### 间距与栅格

4px 基准 12 级（4 → 96px，另加 128px 供 Web 展示面）。卡片内边距 24、组件间距 24、段落 32、章节 48、Web 大区块 104。12 列栅格：xs 4 列 / sm 8 列 / md–xl 12 列，槽宽 16–24，内容区上限 1200px，数据大屏 1440px。主内容:侧栏 ≈ 8:4。

### 背景

产品界面：纯宣纸白平面，**无渐变、无纹理、无插画背景**。层级只靠表面色（page / sunken / card / raised）与 1px 描边表达。
品牌展示面：全幅实景摄影 + 自下而上的墨色保护渐变（`linear-gradient(to top, rgba(16,13,10,.92), transparent)`）承载反白文字。深色区块用 `--ink-900` 实色，不用渐变。

### 影像

纪实 · 人文 · 自然光 · 低饱和。基准图是黄昏暖调的园区航拍——工业设施与农田、林地、光伏阵列共处于同一画面，色温偏暖，天空有云层层次。不摆拍、不过度修图、不用绿色滤镜美化。人像遵循 DEI 多元代表。**当前仅有 1 张影像资产，需要补充图库。**

### 圆角

2 / 4 / 6 / 10 / 16 / 24 / full 七级。产品按钮与输入框 6px；标签 4px；下拉与气泡 10px；卡片与弹窗 16px；营销 CTA、状态点、头像全圆。

### 面板长什么样

**默认平面**：`background: #FFFEFB` + `border-radius: 16px` + 32px 内边距，**无描边、无阴影**。界面靠中性画布（`--surface-sunken`）与纯白面板之间的明度差划界，不靠框线。这是上一版最主要的修正——「白底 + 1px 描边 + 阴影」三重边界让一屏十个同权重的框互相争抢。

三种 `variant`：`flat`（默认）· `outlined`（仅当与同色背景相邻时）· `elevated`（仅真正的悬浮层）。**禁止描边与阴影同时出现。** 面板标题是宋体 24px；需要更小标题说明这块内容不该成为面板。一屏两三个面板就够，其余内容直接放在底色上用 1px 墨线分隔。

**禁止**只带彩色左边框的圆角卡片；左侧 3px 色条只表示「当前选中」。

### 阴影

六级，全部为暖墨投影 `rgba(26,22,18,α)`，α 从 .04 到 .10。卡片 `sm`、hover `md`、抽屉 `lg`、弹窗 `xl`。焦点光环单列一档：`--ring-focus` = 3px 品牌色 22% 混色。

### 描边

hairline 1px（默认分隔与卡片）、emphasis 2px（表头下划线、Tabs 选中）、indicator 3px（选中行、Toast 语义条、抽屉标题条、哲学锚点）。

### 动效

| 类型 | 时长 | 缓动 |
|------|:---:|------|
| 微交互 | 150ms | `--ease-out` |
| 页面过渡 / 弹层 | 300ms | `--ease-emphasized` `cubic-bezier(.16,1,.3,1)` |
| 叙事入场 | 500ms | `--ease-brush`（起笔重、收笔轻） |
| 循环 | 2400ms | linear |

**动效词汇只有三样**（品牌展示面用，产品界面不用）：
- `Reveal` 滚动揭示 —— 进入视口后上浮淡入，`index` 错峰不超过 6 级（约 420ms）
- `RuleReveal` 细线绘入 —— 1px 墨线从左向右展开，作章节分隔的入场
- `Marquee` 走马灯 —— 品牌词条横向滚动，一页最多一次，不低于 30s/圈

hover 的位移一律 4–6px 并配 `--ease-emphasized`。**无弹跳、无缩放入场、无视差。** 全局尊重 `prefers-reduced-motion`（令牌自动降到 1ms，Reveal / Marquee 内部另有 matchMedia 判断）。

### 交互状态

- **Hover**：加深底色一档（600→700）+ 阴影升一级；幽灵/文字按钮改为 `--surface-hover` 浅底。不用透明度变化。
- **Press**：`scale(.98)` + 底色再深一档（700→800）。
- **Focus**：2px 品牌色描边 + 2px offset；输入类另加 3px 光环。焦点永远可见。
- **Disabled**：`opacity: .4` + `cursor: not-allowed`。
- **Selected**：品牌色 6% 底 + 左侧 3px 指示条（表格行）或品牌浅底 + 品牌字色（导航）。

### 透明度与模糊

只在两处使用：粘性顶栏（`color-mix` 88% 页面色 + `backdrop-filter: blur(12px)`）与模态遮罩（`rgba(26,22,18,.45)`）。**正文与图标一律满不透明度**——不用 alpha 调淡文字，要淡就换 Ink 色阶。

### 固定元素

顶栏 sticky 64px（官网 72px）；侧轨 76/264px 固定全高；抽屉右侧 380px；Toast 顶部居中；弹窗视口居中，最大高 86vh 内部滚动。

## 4. ICONOGRAPHY · 图标系统

**当前方案**：Material Symbols Rounded 可变字体，从 Google Fonts CDN 加载（已写入 `tokens/fonts.css`），全系统只经 `<Icon>` 组件渲染。规格：24px 网格、`wght 400`（≈2px 笔画）、描边为默认（`FILL 0`），尺寸四级 18 / 20 / 24 / 48。选中态的导航图标切 `FILL 1`。

**⚠️ 图标替代说明（需用户补件）**：V37 文字稿规划了 150 枚品牌自定义 SVG —— 太极流纹 12 变体、五实体各 6 枚专属图标（共 30 枚）、14 种图表图标 —— 但**未提供任何 SVG sprite 或图标文件**。按「不凭记忆重绘品牌资产」的原则，本系统**没有绘制**这些图标，改为：

- 通用与业务图标 → Material Symbols Rounded（原稿本身也规划了 204 枚 Material Symbols，风格一致，是最近的替代）
- 太极流纹 Loading → `TaijiSpinner` 用阴阳双弧旋转的极简几何**临时占位**，并在组件文档中标注待替换
- 五实体专属 30 枚 → 暂用语义最近的 Material Symbols（STE `bolt` / `local_fire_department` / `eco` / `grass`，STI `directions_boat` / `receipt_long`，STH `science`，EDU `school`，STG `hub` / `gavel`）
- 33+ 幅品牌插画（Hero / 空状态 / 场景叙事）→ **完全缺失**。空状态目前用 Material Symbols 圆底图标占位

## 6. 十条工艺准则

1. 颜色只用令牌，不硬编码色值
2. 间距只用 4px 步进的令牌
3. 主操作用玄墨；实体色只作身份标记；朱与金各不超过一处
4. 不用纯黑 `#000` / 纯白 `#FFF` 作为文字或页面底色
5. 动效即叙事，不做无意义动效
6. 组件覆盖 8 状态：idle / hover / focus / active / loading / success / error / disabled
7. 每个交互元素可键盘操作，焦点永远可见
8. 正文对比度 ≥ 4.5:1（WCAG 2.2 AA），触摸目标 ≥ 44×44px
9. 暗色模式走 `data-color-scheme="dark"`，不另写一套组件
10. 五实体只通过 `data-theme` 切换主色，版式与组件零差异
