MOTIONMotion & Interaction

动效：编排、缓动与连续

动效即叙事，不做无意义动效。本章把 --dur-* 与 --ease-* 两族令牌兑现为可操作的编排规则：动效词汇只有三样——Reveal 滚动揭示、RuleReveal 细线绘入、Marquee 走马灯，且只用于品牌展示面，产品界面不用。hover 位移一律 4–6px。无弹跳、无缩放入场、无视差。本章所有演示都可以动手调参。

开物共生
M.1

动效的唯一理由

六个目的 · 服务不了就删掉

多余的动效是负债，不是加分。评审一个动效只问一句：它服务下列哪一个目的？答不上来，删。第二条铁律是「快比慢安全」——大多数 UI 过渡落在 150–300ms；超过 400ms 的非叙事动效会让界面显得迟钝，只有叙事性、展示性动效才可以长。

六目的每个动效在代码评审时都要能指认其一
引导
把注意力导向某处，建立阅读顺序。
本站：首页依阅读顺序 Reveal 入场
反馈
确认操作被接收，让点击有回响。
本站：按压 scale(.98) + 底色深一档 · 80ms
解释
让状态变化可理解：来源方向即因果。
本站：抽屉自右入、亦自右出
连续
维持对象的空间连续性，界面像实物。
本站：跨页 View Transition · 顶栏墨痕
愉悦
注入品牌情绪，一瞬即收。
本站：印章落定 · 运笔收锋
叙事
滚动推进故事，移步换景。
本站：章节细线绘入与滚动揭示
M.2

缓动是性格 Easing

5 条曲线 · 全站不得出现第六条

缓动曲线决定动效的气质，比时长更影响观感。全站只用下列五条；一屏之内的所有动效共享同一缓动族，界面才像出自同一套物理规则。几乎不用 linear 做位移与淡入——除了无限循环与滚动绑定。没有弹簧曲线：overshoot 会把克制的界面拉向廉价。指针悬停或点击任一卡片即可播放。

缓动族曲线图为实测贝塞尔控制点，轨道为实时播放悬停播放
--ease-standard中性利落
通用过渡。没有特别理由时用这条。
--ease-emphasized品牌缓动
页面过渡与弹层入场；hover 的 4–6px 位移也走这条。
--ease-out减速到位
微交互：hover 变色、图标切换、开关。
--ease-in果断离开
退场、收起。别让用户等一个他已经决定丢弃的东西。
--ease-brush落笔
叙事入场：起笔重、收笔轻。Reveal 与 RuleReveal 用这条。
linear仅循环
只用于无限循环（走马灯 · Spinner）与滚动绑定。匀速位移看起来机械。
M.3

时长尺度与进退场不对称

退场比进场快一档

进场稍慢、用 emphasized 或 brush 到位，让人看清新内容来自哪；退场更快、用 ease-in 加速离开。二者的方向必须呼应来源：从右侧划入的抽屉，退场也回到右侧。下方左栏是全部时长令牌的相对长度，右栏可以亲手对比同一元素的进与退。

时长令牌条长 = 相对时长

M.4

Reveal 滚动揭示

错峰不超过 6 级（约 420ms）

三样动效词汇之首。元素进入视口后上浮淡入；同组元素按 index 错峰，但不超过 6 级——再多就成了等待。拖动滑杆亲自找那条界线：步长太大显拖沓，太小看不出节奏。本典列表与网格统一取 70ms。

Reveal调参后自动重播；进入视口时首播一次
延迟在第 6 级封顶（min(index, 5)），所以再长的列表最多也只等 420ms。
M.5

RuleReveal 细线绘入 · Marquee 走马灯

章节分隔的入场 · 一页最多一次

RuleReveal：1px 墨线自左向右展开，作章节分隔的入场。它是「细线划界」这条视觉规则在时间轴上的兑现——界面靠明度差与细线划界，那么线的出现本身就该是一个动作。Marquee：品牌词条横向滚动，作章节之间的呼吸段，一页最多一次，不低于 30s/圈；太快就成了广告牌。本页页脚即是全站唯一的一处走马灯。

M.6

滚动驱动的实现优先级

原生优先 · 观察者兜底 · 内容默认可见

实现优先级从轻到重：原生 CSS 滚动驱动动画（animation-timeline: view()）→ IntersectionObserver + class → 时间线库。本站走前两级，不引第三方库。关键契约：内容默认可见——入场的初始态由 JS 施加，只有在确认原生不可用且非 reduced-motion 时才给 html.js-rv。动效层挂了，站仍是一份能读的文档。不做视差：层间速度差会引发前庭不适，且与「平面优先」的材质逻辑相悖。

视口驱动在下方小窗内滚动
触发式：进入视口播放一次，适合入场与数字滚动。
绑定式（scrub）：动画进度 = 滚动进度，可来回。本站只用于量表与柱条的生长。
只动 transform 与 opacity——这两个属性走合成器线程，是 60fps 的前提。
动 width / height / top / left / margin 会触发重排，是卡顿之源。
reduced-motion 下保留终态与透明度变化，关闭 scrub。
M.7

东方动效：間与运笔

轻 · 慢 · 含蓄

东方动效的内核是节奏与从容，不是某种特效。間（留拍）——动效在关键处停一拍再继续，是时间的留白；水的隐喻——以 emphasized 与 brush 为主，有重力与惯性，时长偏长而不弹跳；书法运笔——SVG 路径以 stroke-dashoffset 书写，配 --ease-brush（起笔重、收笔轻）。下面是「永字八法」的抽象转译：八笔依次落墨，末了钤印。

M.8

状态编排：加载、反馈与浮层

空态与错态才是专业度的分水岭

骨架屏到内容不是「换一批 DOM」，而是一次编排：骨架的呼吸停止、内容按行 Reveal 落位、布局不得抖动。浮层同理——模态自 emphasized 入场、遮罩同步渐显；Toast 从顶部居中滑入、3 秒后自行退场。三者用的是同一族缓动，所以像出自同一套物理规则。

M.9

无障碍契约与性能预算

reduced-motion 是硬要求，不是可选项

前庭功能障碍者会因大位移与视差产生真实的生理不适。prefers-reduced-motion: reduce 下我们不是全关，而是让时长令牌降到 1ms：动作瞬间到终态，界面仍然完整。性能上目标 60fps（16.7ms/帧），只动 transform 与 opacity；透明度与模糊只在两处使用——粘性顶栏与模态遮罩。

该做
  • 只动 transform 与 opacity；显隐用 opacity + visibility。
  • 退场比进场快一档，方向呼应来源。
  • hover 位移一律 4–6px，配 --ease-emphasized。
  • reduced-motion 下给终态，内容永不因动效失败而消失。
  • 入场的初始态由 JS 施加：无脚本时内容默认可见。
不该做
  • 弹跳与 overshoot：本系统没有弹簧曲线。
  • 缩放入场：入场只做位移与透明度。
  • 视差：层间速度差引发不适，且与平面优先相悖。
  • 指针跟随物、磁吸、聚光：装饰性动效，无目的即删。
  • 动 width/height/top/left/margin——触发重排。
本站的实现契约。全站揭示优先走原生 animation-timeline: view()；不支持时才由 motion.js 加 html.js-rv 并用 IntersectionObserver 补位。两条路径都以「内容默认可见」为基线。
