00.1

三维价值与设计誓约

全典一切决策的最终仲裁标准
守正
Preserving Integrity · Know Thyself

我承诺品牌不漂移、设计不媚俗。每一个像素都忠诚于源裕兴的价值根基。在本典中：令牌是唯一可信源，600 阶锚点原值锁定，对比度门禁不通过即构建失败。

开物
Pioneering Innovation · Make Things Happen

我承诺在经典框架中打开新的可能。不因循守旧，不盲目标新。在本典中：OKLCH 感知色阶、三态暗色、数据墨色的 CVD 枚举、AI 原生的置信度编码，皆在 Geist 的纪律里注入东方百年字号的血。

共生
Symbiotic Coexistence · Flourish Together

我承诺设计首先服务于人，再服务于品牌，最后服务于自己。在本典中：WCAG 2.2 AA 是出厂设置，五实体共用一套语法而各自生长出色彩身份，键盘可达与 reduced-motion 不是附加项。

00.2

原子设计六层：一墨成城

Brad Frost 五层 + 令牌亚原子层，组合方向只向上
令牌亚原子。色、字、距、形、动、层的唯一事实。本身不可用，须附着于原子。--stg-600 · --space-4 原子不可再分的功能单元：按钮、输入、图标、徽标、印章、太极 Spinner。.a-btn · .a-input 分子原子的最小有意义组合，单一职责：表单字段、搜索框、KPI 瓦片、实体切换器。.m-field · .m-kpi 有机体可独立运作的区块：顶栏、侧轨、数据表、图表面板、表单段、对话框、AI 面板。.o-table · .o-chart 模板只定结构、不含真实内容的页面骨架：看板、文档、列表–详情、品牌页、陈述。.t-dashboard 页面模板注入真实内容后的最终形态，也是检验系统的场所：五实体各一页。.p-frame[data-theme]
守正共生
原子设计不是分类法，是生长秩序。V37 让宪法长出了双手；V38 让双手长出了骨骼——每一个组件都能回答「我由什么组成、我被谁组成」。分子只由原子构成，有机体只由分子与原子构成，模板不含数据，页面必须有真实数据。这条单向的组合链，就是守正在结构层面的兑现；五实体共享同一条链而各自换色，就是共生。
— 卷首哲学锚点 · 守正 + 共生
如何阅读本典。顶栏可随时切换五实体与浅 / 暗色，整部全典（含所有样张与五个页面）会即时重新解析令牌。按 ⌘K 跳转任意章节；点击任何色块可复制其令牌名；带「代码」的样张可展开源码。
一点朱。全典每屏只有一个用力之处：主标题、一方印章或一个主按钮。其余皆秀承——这是印章逻辑在版面上的兑现，也是本典自己的对比预算。
00.3

三个方向标杆：取其法，不取其貌

Ledgerix · PRODIGIES · Sui
Benchmark 01 · Dashboard
Ledgerix CRM · FMS
看板的信息密度秩序
  • 看板骨架固定为「侧轨 + 顶栏 + 筛选行 + KPI 行 + 图表 + 表」，读者先看摘要再看明细——本典 T1 模板与 STG / STE 页面沿用此秩序。
  • 页面底与卡片底分两级纸色（Ink 100 / Ink 50），层级靠发丝线与极轻阴影，而非厚重投影。
  • 状态色（成功 / 警告 / 错误）与品牌强调色分离，状态永远带图标与文字。
  • 不取：SaaS 通用的纯灰中性与蓝色主色——源裕兴以宣纸墨色与五实体色替代。
behance.net/gallery/232976091
Benchmark 02 · Brand × Product
PRODIGIES
瑞士极简的纪律与单一信号色
  • 深黑 #000 与浅灰 #F2F2F2 铺中性地，一个信号色只用于关键转化、焦点态与交互标签——这正是「藤黄戒律」与「一点朱」的当代同构：本典把高饱和留给主按钮、焦点环与印章。
  • 纪念碑式的字体与严格栅格建立权威感——本典 Display 档用力，H2 以下秀承；12 列栅格是第一宪法。
  • 每一个输入、标签、复选框与按钮态都被逐一定义，跨数百个视图保持一致——本典的 8 状态机与状态矩阵由此校准。
  • 不取：纯黑纯白与荧光绿——源裕兴用玄墨 / 宣纸白与朱砂。
behance.net/gallery/247882287
Benchmark 03 · Identity → Website
Sui（Holographik）
品牌到网站的一体化系统
  • 色板收束到本质：一个核心识别色 + 黑白 + 带该色相偏移的灰阶——本典的 Ink 九阶带暖色相偏移，五实体只换主色不换中性。
  • 全系统单一字体（TWK Everett）兼顾开发者文档与产品界面——本典以思源黑 / 宋 + Inter + JetBrains Mono 五族分工，但坚持「一页 ≤ 两个家族」。
  • 渐变以三层叠加（渐变 + 颗粒 + 色相罩染）作为功能性元素表达流动与深度——本典把太极流纹与「源」的水意，落为 Loading、Hero 与分隔的功能性母题，而非贴图。
  • 不取：面向加密世界的电蓝气质——源裕兴要的是厚德之温而非合成之冷。
