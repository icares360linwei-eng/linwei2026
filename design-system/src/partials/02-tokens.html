设计令牌：亚原子层

令牌是构成原子的亚原子粒子：--stg-600 本身没有功能，它必须附着于按钮的底色才活过来。本层只定义一次（Primitive），语义层只引用原始层，组件层只引用语义层；五实体切换只替换 --e-* 映射，暗色模式只替换语义层。任何组件 CSS 出现字面色值或魔法数字，即违反守正。

60 · 30 · 10 法则（Token 级）

  • 60% 中性表面——只允许引用 Ink 色阶（--surface-page / surface / outline*）。
  • 30% 主色系——--brand-600 / primaryContainer / brand，随 data-theme 切换。
  • 10% 古铜金 + 语义 + 数据墨色——可在构建时 lint：任何组件底色引用 --gold-* 超过一处即警告。

暗色模式：三态解析，不是反转 开物

暗色是独立设计：页面底取玄墨 Ink 900，表面取浓墨 Ink 800，主色取实体 300 阶（提亮 + 微降色度），投影换成描边 + 微光。解析有三态——宿主显式选择（:root[data-theme="dark|light"]）、系统偏好（prefers-color-scheme）、本典自身的 data-color-scheme="auto|light|dark"；显式选择永远胜过系统偏好，且完整的浅色定义放在裸选择器上，保证任何一态都不会出现「一种主题的文字落在另一种主题的底上」。

/* 浅色：完整定义在裸选择器上，嵌套 [data-theme] 重新解析 */
.sino, .sino [data-theme] { color-scheme: light; --surface-card: var(--ink-50); … }

/* 暗色三态：本典显式 / 宿主显式 / 系统偏好（显式优先） */
.sino[data-color-scheme="dark"],
:root[data-theme="dark"] .sino:not([data-color-scheme="light"]) { --surface-card: var(--ink-800); … }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) .sino:not([data-color-scheme="light"]) { … }
}
/* 五实体：只替换映射 */
[data-theme="ste"] { --brand-600: var(--ste-600); --brand-600: var(--ste-600); --brand-600: var(--ste-300); }

数据墨色：与实体同色相，经 CVD 六检枚举的固定顺序 验证通过

图表系列色不能直接用品牌色：石青与古铜金的色度低于 0.10，在图表里读作灰；实体 300 阶又超出暗色明度带。因此本典单独推导「数据墨色」——与实体同色相，色度提升到 ≥ 0.11，明度落在各模式色带内——再对 5! 种顺序逐一运行色觉缺陷模拟（Machado 2009），取相邻对 ΔE 最小值最大的顺序。槽 1 固定为母品牌玄紫。颜色跟随实体而非排名：筛选掉一个系列，幸存者不换色。

中西文混排纪律

  • 间隙 0.12–0.25em。中文与英文 / 数字之间留隙，用 text-autospace: normal 渐进增强；「12,800 吨」而非「12,800吨」。
  • 字距按档分流。Display / H1 收紧 −0.01 ~ −0.02em；H2 / H3 微疏 +0.01em；正文归零，勿正勿负。
  • 标点悬挂 + 避头尾。hanging-punctuation: first allow-end; line-break: strict，边缘如刀裁。引号分治：中文「」，西文 “”。
  • 数字对齐。表格、编号、轴刻度用 tabular-nums；KPI 大数字用比例数字，且必须用 Inter 而非宋体（宋体数字在看板上读作装饰）。
  • 行宽。中文正文 25–38 字（max-width: 38em），西文 45–75 字符；本典 prose 锚在 38em。
  • 一页 ≤ 两个字体家族。五族是词汇表，不是同时出场的理由：文档页 = 宋 + Mono；产品页 = 黑 + Inter。
