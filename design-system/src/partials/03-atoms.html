LAYER 1Atoms

原子：不可再分的功能单元

原子是拆到底就失去功能的界面元素：一个按钮、一个输入框、一枚图标、一方印章。它们只消费组件令牌，从不包含其他原子；每个原子都定义尺寸档、变体与完整的 8 状态机，并自带键盘可达与焦点可见。

  • 状态机 idle → hover → focus-visible → active → loading → success → error → disabled；焦点环 2px 主色 + 5px 22% 光环，永不用 outline: none 裸删。
  • 图标 按钮内图标 18px，与文字按视觉中线对齐；图标按钮必须有 aria-label。
  • 文案 动词 + 宾语：「删除订单 #1024」而非「是」；「保存并提交」而非「确定」。
  • 五实体 主按钮底色随 data-theme 切换，STH 自动落到可访问的 700 阶；Danger 恒为朱砂，不随实体漂移。
