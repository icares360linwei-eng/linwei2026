治理：让系统在生长中不漂移

工具可以换，令牌的单一可信源不可换。本章把品牌宪法翻译成可执行的规则：核心十条、原子设计五律、命名、状态机、门禁、无障碍清单、与 Ant Design 及 Odoo 18 的映射，以及本版对 V37 文字稿的每一处修正。

守正
G.1

核心十条（工艺判断准则）

  • 颜色只用令牌，不硬编码色值。
  • 间距只用 4px 步进的令牌。
  • 实体主色仅用于 Primary 操作与重点元素；面积不超过 30%。
  • 不用纯黑 #000 / 纯白 #FFF——用 Ink 900 / Ink 50。
  • 动效即叙事，不做无意义动效；退场快于进场。
  • 组件遵循 8 状态机。
  • 每个交互元素可键盘操作，焦点可见。
  • 正文对比度 ≥ 4.5:1，UI 边界 ≥ 3:1（构建时实测）。
  • 暗色模式三态解析：data-color-scheme / 宿主 / 系统偏好。
  • 五实体通过 data-theme 切换，只替换映射，不漂移。
G.2

原子设计五律与 lint 规则

律规则可检
一 · 单向组合原子 → 分子 → 有机体 → 模板 → 页面；下层不得引用上层。.a-* 内不得出现 .m-/.o-
二 · 分子单责一个分子只做一件事，可被任何有机体复用。评审
三 · 有机体独立有机体可单独运作，不依赖页面上下文；不互相嵌套为分子。.o-* 内不得嵌套 .o-*（外壳除外）
四 · 模板无数据模板只含占位（.wf），任何真实数值出现即违规。.t-* 内禁止数字字面量
五 · 页面有真数页面必须注入真实内容并标明数据截止；空页面不是页面。Design QA
Lint触发级别
no-literal-color组件 CSS 出现 #hex / rgb() / oklch() 字面量阻断
no-magic-spacingpadding / margin / gap 非 --space-* 且非 0阻断
layer-referenceComponent 令牌引用 Primitive；Semantic 引用 Component阻断
gold-budget同一视图 --gold-* 作底色超过 1 处警告
contrast-aa语义色对实测 < 4.5:1（文字）/ 3:1（边界）阻断（已内置于 build.mjs）
no-important出现 !important（第三方覆盖除外）警告

G.4

质量门禁：构建门禁 + 四阶评审 + Design QA

构建门禁（自动）
build.mjs · 退出码 1 即阻断
  • 五实体可访问主色选取（浅 / 暗）。
  • 20 项语义色对比度实测。
  • 数据墨色六检（明度带 · 色度 · CVD ΔE · 正常视觉 ΔE · 对比 · 固定顺序）。
  • 令牌引用层级合法性（未知引用即失败）。
  • 令牌计数注入页面（数字必真）。
四阶评审（人工）
自审：WCAG · 五实体切换 · 五断点
同行审：BEM · 令牌引用 · 原子五律
跨职能审：前端 · Odoo · 内容
品牌审：哲学对齐 · 品牌委员会
Design QA 检查项
  • 像素偏差 < 2px；色彩 100% 令牌引用。
  • 间距 100% 4px 步进；字体完全匹配。
  • 五断点响应；动效视觉匹配。
  • WCAG 全通过；五实体切换无异常。
  • 性能：Lighthouse ≥ 95 · LCP < 2.5s · CLS < 0.1 · CSS < 50KB（压缩后）。

V39.0 · 墨经光纬（多页面站点版）
